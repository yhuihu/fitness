# 健身计划制定器 App

## 概述
一个安卓健身计划管理应用，专为 vivo x200 pro mini 设计，支持：

1. **自定义健身计划制定**
   - 用户自行输入计划名称
   - 设置循环时长（分钟）
   - 为每个计划项输入组数
   - 为每个组设置组间休息时间（秒）

2. **每个计划项完整配置**
   - 输入每组做多少次练习（重复次数）
   - 设置组间休息时间（配有倒计时功能）

3. **训练模式**
   - 循环播放所有计划项
   - 组间倒计时功能
   - 可选择跳过休息或继续训练

## 开发说明

### Android原生版本
1. **打开 Android Studio**
2. 选择 "Open" -> 打开 `fitness-app/app/` 目录
3. Android Studio 会自动同步 Gradle 配置
4. 连接 vivo x200 pro mini 设备或使用模拟器
5. 点击运行按钮 (绿色三角形)

### HTML5 版本（无需编译）
直接在手机浏览器中打开 `fitness-app/app/src/main/assets/index.html` 即可使用所有功能，无需安装任何应用。

## 功能详解

### 计划制定页面
1. 在 "计刽名称" 中输入计划名称（如: "力量训练计划"）
2. 在 "循环时长(分钟)" 中设置每个循环的时长
3. 点击 "添加训练项" 按钮
4. 在弹出的对话框中：
   - 输入 "组数"（每组做多少次练习）
   - 输入 "组间休息(秒)"（组之间的休息时间）
   - 点击 "保存"

### 训练页面
1. 填写完所有计划项后，点击 "开始计划"
2. App 会按顺序展示每个计划项
3. 每个计划项会按组数依次进行：
   - 进行训练（倒计时显示）
   - 组间休息（带倒计时）
   - 休息结束后自动进入下一组
4. 可以在休息时点击 "跳过休息" 直接继续
5. 完成所有计划项后显示完成提示

## 注意事项
- HTML5 版本适合快速测试和在任何设备上使用
- Android 版本需要 Android Studio 环境和真机/模拟器
- 对于 vivo x200 pro mini，建议使用 Android Studio 的真机调试功能
- 建议在真机上测试倒计时功能的准确性
